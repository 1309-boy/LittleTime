# LittleTime

학교와 마을을 오가며 생활 상태, 능력치, 돈, 사람들과의 관계를 관리하는 텍스트 생활 시뮬레이션의 첫 뼈대입니다. 현실적인 학원물에 작은 오컬트 사건을 섞었습니다.

## 현재 플레이할 수 있는 것

- 검은 배경, 흰색 텍스트, 왼쪽 고정 메뉴. 모바일에서는 메뉴가 위쪽으로 이동합니다.
- 7개 거리의 연결 지도. 연결된 거리만 도보로 이동하며 5분이 흐릅니다.
- 1,500원을 내고 원하는 거리로 이동하는 버스. 첫 버전에서는 5분이 흐릅니다.
- 학교 수업, 식사, 수면, 청소, 공부, 운동, 춤, 편의점/카페 아르바이트.
- 스트레스·피로도·배고픔 관리와 힘·체력·외모·속임수·춤·가사·학업 성장.
- 4명의 샘플 NPC와 호감·신뢰. 관계로 열리는 추가 일자리.
- 일요일 21:00의 자동 월세 납부와 연체, 퇴거 예고, 임시 숙소, 복귀.
- 일반 번호 선택지와 라디오 선택 후 `(1) 다음`으로 확정하는 선택지.
- 밤 20:00 이후 옛 역 거리의 오컬트 샘플 사건과 아이템 조건부 대화.
- 브라우저 자동 저장과 수동 세이브 슬롯 1~10. 날짜·위치·잔액·저장 시각 표시, 덮어쓰기/불러오기 확인. 새 게임을 시작해도 슬롯은 유지됩니다.
- JSON 파일 다운로드/불러오기. 대화 중 선택도 복원됩니다.

## 실행

설치나 빌드가 필요 없는 정적 HTML + JavaScript 모듈입니다. 로컬에서 파일을 더블클릭하면 브라우저의 모듈 제한으로 동작하지 않을 수 있으니 HTTP 서버로 열어 주세요.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 검증

Node.js 20 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm run check
npm test
```

## 수정할 파일

| 파일 | 역할 |
| --- | --- |
| `src/world.js` | 거리 연결, 장소, NPC, 아이템, 행동, 대사, 시간과 비용 |
| `src/engine.js` | 게임 상태, 시간 경과, 월세 처리, 이동, 저장 검증 |
| `src/save-slots.js` | 브라우저 저장 슬롯 1~10 |
| `src/app.js` | 화면, 선택지, 지도, 팝업, 파일 저장/불러오기 |
| `src/styles.css` | 흑백 UI와 모바일 레이아웃 |
| `src/art.js` | 거리 지도와 장면의 SVG 선화 |
| `docs/AUTHORING.md` | 새 장면과 행동을 추가하는 방법 |
| `docs/DESIGN.md` | 첫 버전에서 적용한 규칙과 임시 수치 |

콘텐츠는 자바스크립트의 데이터 객체로 작성합니다. Ink는 아직 연결하지 않았으며, 스토리가 커질 때 실행 엔진과 UI 사이에 어댑터를 추가할 수 있도록 나눴습니다.

## GitHub Pages

이 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하고, `main` 브랜치와 `/(root)`를 지정하여 저장합니다. `.nojekyll`을 포함했으며, 모든 자산 경로는 프로젝트 하위 경로에서도 작동하는 상대 경로입니다.

공개 저장소가 필요한 계정이라면 저장소의 공개 범위를 먼저 변경해야 합니다. 사이트는 정적 게임이므로 별도의 서버, API 키, 계정 연결이 필요하지 않습니다. 저장 데이터는 플레이어 브라우저와 직접 내려받은 파일에만 보관됩니다.

## 첫 플레이 동선

첫 선택 → 자취방에서 식사 → 학교까지 도보 → 08:30 이후 수업/하린과 대화 → 상점가 아르바이트 → 식사와 휴식 → 집에서 수면.

이름과 대사, 비용 및 밸런스 수치는 시연용이며 이후 세계관과 캐릭터 기획에 맞춰 변경할 수 있습니다.
