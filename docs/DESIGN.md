# 첫 뼈대의 게임 규칙

## 확정된 방향

- 현실적인 학교생활과 마을 아르바이트를 중심으로 살아가는 텍스트 게임.
- 주인공은 자취하며 매주 돈을 내야 한다.
- 이름 있는 NPC들과 관계를 쌓으며 이야기를 진행한다.
- 마을은 거리들로 나뉘고 집/학교/상점은 거리 안의 장소이다.
- 연결된 거리만 걸어갈 수 있고 한 번에 5분이 흐른다.
- 지도상의 이동 가능한 거리 그림을 눌러 이동할 수 있다.
- 각 행동에 정해진 시간이 흐르고, 버스는 돈을 내고 원하는 거리로 이동한다.
- 스트레스·피로도·배고픔, 힘·체력·외모·속임수·춤·가사 등의 능력치를 관리한다.
- 평범한 일상 속에 오컬트 요소가 등장한다.

## 시연을 위한 임시 설정

| 항목 | 첫 버전 |
| --- | --- |
| 시작 | 2026년 4월 6일 월요일 07:30 |
| 거리 | 주택가, 학교 앞, 도서관, 중앙, 상점가, 강변, 옛 역 |
| 시작 소지금 | 62,000원 |
| 월세 | 매주 일요일 21:00, 80,000원 |
| 버스 | 아무 거리에서 다른 거리로 1,500원, 5분 |
| 아르바이트 | 편의점 2시간 24,000원, 카페 2시간 25,000원 |
| 수업 | 평일 08:30~15:00 사이에 마칠 수 있는 2시간 행동, 하루 한 번 |
| 관계 | 호감/신뢰 각각 0~100 |
| 상태/능력치 | 0~100. 생활 상태는 낮을수록 좋고 능력치는 높을수록 좋음 |
| NPC | 하린, 민재, 서윤, 집주인 박정숙 |

현재 수업은 하루의 일부를 대표하는 샘플이며 정교한 시간표와 성적 평가, 축제 스토리는 이후 확장할 영역이다. 각 NPC의 대화는 하루에 한 번 관계를 올릴 수 있다.

## 주거

일요일 21:00에 현재 주의 월세와 기존 연체료를 낼 수 있으면 자동 납부한다. 잔액이 부족하면 이번 주의 80,000원이 미납액에 더해지고 스트레스와 집주인 신뢰에 영향이 생긴다.

첫 주는 경고, 둘째 주부터 연체 때마다 8,000원의 연체료를 추가하며 전체 연체료 상한은 24,000원이다. 셋째 주에는 일주일 뒤 퇴거 예고를 받는다. 기한까지 해결하지 못하면 임시 숙소에 머물고 수면의 회복량이 줄어든다. 임시 숙소 기간에는 새 월세가 추가되지 않으며 기존 빚을 갚으면 자취방으로 복귀한다. 이 과정에서 게임은 종료되지 않는다.

## 시간과 저장

메뉴 확인, 지도 열기, 장소 출입, 라디오 선택만으로는 시간이 흐르지 않는다. 도보/버스 이동, 대화 확정, 식사, 일, 휴식에는 정해진 시간이 흐른다. 수면처럼 긴 행동을 해도 납부 시각과 결석 확인은 순서대로 처리한다.

파일에는 현재 거리/장소, 시간, 생활 상태, 능력치, 돈, 소지품, NPC 관계, 월세, 방문 기록, 스토리 플래그, 현재 대화와 라디오 선택, 최근 기록이 포함된다. 화면 설정은 해당 브라우저에 따로 저장한다.

## 이후 추가하기 좋은 것

NPC별 긴 스토리와 관계 단계, 여러 종류의 주거, 일자리의 채용 조건, 학교 시간표와 시험, 의상/장비, 오컬트 사건, 게임 내 스크립트 디버그 창.
